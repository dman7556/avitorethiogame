# AI IMAGE PROMPT — Original Rocket Icon

*(for tools like Midjourney, DALL-E, Ideogram, Stable Diffusion, etc.)*

---

## MAIN PROMPT

> "Flat vector icon of a rocket launching at a steep diagonal upward angle,
> viewed from the side. Bold solid silhouette style with minimal internal
> detail — simple geometric shapes for the cylindrical body, pointed nose
> cone, and a single circular porthole window. Three angular fins: two on
> the sides near the tail and one pointing straight back. A tapering flame/
> exhaust trail extends from the rear, made of simple overlapping triangular
> shapes, fading in opacity toward the tip. Two-tone color palette: bold
> red/crimson silhouette on a solid black rounded-square background, no
> gradients, no shading, no photographic detail, no stars or space
> background. Clean, confident, minimal icon aesthetic. Icon should read
> clearly at small sizes (app icon scale) with strong, simple silhouette
> shapes. No text, no lettering, no watermark."

---

## STYLE MODIFIERS

Add any of these depending on the tool:

- "flat design, vector illustration, app icon"
- "high contrast, bold silhouette, negative space"
- "minimalist, geometric, 2-color palette"
- "sticker style, die-cut illustration"
- "steep 40–45 degree upward launch angle"

## NOTES

- This describes an **original** rocket icon design — a different composition
  and subject from earlier biplane/jet concepts, not a reproduction of any
  existing logo or trademarked artwork.
- Want the fins larger, the flame trail longer, or the angle steeper/shallower?
  Add that detail directly into the main prompt line — specificity gives more
  consistent results across different AI tools.
- For a full brand identity, design this icon and any wordmark/text
  **separately**, then combine them yourself in a layout tool — keeps both
  pieces fully original.
- If the AI result drifts (extra details, wrong angle), regenerate with the
  same prompt + seed rather than editing the prompt heavily; flat 2-color
  icons can require a few rolls to get a clean silhouette.
