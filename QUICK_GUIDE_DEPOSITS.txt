================================================================================
                    ADMIN DEPOSIT APPROVAL - QUICK GUIDE
================================================================================

STEP 1: CLEAR BROWSER CACHE (IMPORTANT!)
--------
Windows: Press Ctrl + Shift + Delete
         Select "All time" → Check "Cached images and files" → Clear data
Mac:     Press Cmd + Shift + Delete

OR simply Hard Refresh:
Windows: Press Ctrl + Shift + R
Mac:     Press Cmd + Shift + R

STEP 2: GO TO DEPOSITS PAGE
--------
Type in browser address bar: /admin/deposits
Press Enter

OR full URL: http://localhost:5173/admin/deposits

STEP 3: YOU SHOULD SEE
--------
✓ Search box: "Search by name or email..."
✓ Filter dropdown: Set to "PENDING"
✓ List of deposits with:
  - Thumbnail screenshots
  - User names
  - Amounts
  - Payment methods (CBE, TELEBIRR)
  - Dates
  - Status badges (orange = PENDING)

STEP 4: REVIEW A DEPOSIT
--------
Click any deposit card
→ Details view opens showing:
  ✓ User name, email, phone
  ✓ Payment method
  ✓ Amount
  ✓ Large screenshot from Cloudinary
  ✓ Approve & Reject buttons

STEP 5: APPROVE A DEPOSIT
--------
Click green "Approve" button
→ Approval form opens

Enter credit amount (or keep default)
Click "Review & Confirm"

→ Confirmation dialog opens with 5-second countdown
  Wait... 5
  Wait... 4
  Wait... 3
  Wait... 2
  Wait... 1
  Wait... 0 (button becomes clickable)

Click "Confirm Approval" button
→ ✅ DEPOSIT APPROVED!

List refreshes automatically
Deposit now shows as "APPROVED" (green badge)

================================================================================
                            TROUBLESHOOTING
================================================================================

Problem: Button not showing / Page blank / Nothing happens
Solution 1: Clear cache (see Step 1 above)
Solution 2: Hard refresh (Ctrl+Shift+R or Cmd+Shift+R)
Solution 3: Try incognito/private window
Solution 4: Check if you're logged in as ADMIN

Problem: Approve button doesn't open anything
Solution: Make sure deposit status is "PENDING" (orange badge)
          If green/red, it's already approved/rejected

Problem: Confirmation countdown stuck
Solution: Wait 5 seconds, then try clicking button
          If still stuck, refresh page

================================================================================
                           WHAT YOU'RE APPROVING
================================================================================

When you approve, the system:
✓ Checks you entered a valid amount
✓ Updates the deposit status to APPROVED
✓ Credits the user's wallet balance
✓ Creates a permanent transaction record
✓ Sends the user a notification
✓ Logs the admin action for audit trail

Result: User immediately has funds in their wallet!

================================================================================
                         IMPORTANT REMINDERS
================================================================================

1. ALWAYS clear cache first!
   This is the #1 reason things don't work.
   The browser has cached old code.

2. The page is at: /admin/deposits
   NOT: /admin-deposits (wrong)
   NOT: /dashboard/deposits (that's user page)

3. Wait for 5-second countdown
   This safety feature prevents accidents

4. Check deposit status is PENDING
   If already APPROVED or REJECTED, no button shows

5. Use Cloudinary screenshot to verify payment
   Check amount matches what user submitted
