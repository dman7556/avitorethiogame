ADMIN DEPOSITS APPROVAL
=======================
URL: http://localhost:5173/admin/deposits

What admins can do:
  ✓ View all pending deposits
  ✓ Search by user name/email
  ✓ View user info (name, email, phone)
  ✓ See Cloudinary payment screenshot
  ✓ Enter credit amount to approve
  ✓ Confirm with 5-second countdown
  ✓ Reject deposits with reason

How to approve:
  1. Click deposit card
  2. Review details + screenshot
  3. Click "Approve" button
  4. Enter credit amount
  5. Click "Review & Confirm"
  6. Wait 5 seconds
  7. Click "Confirm Approval"
  ✅ Done!

TROUBLESHOOTING
===============

Problem: Page not loading / Button not working
Solution:
  1. Clear cache: Ctrl+Shift+Delete (or Cmd+Shift+Delete on Mac)
  2. Hard refresh: Ctrl+Shift+R (or Cmd+Shift+R on Mac)
  3. Go to the URL again
  4. Check browser console (F12) for errors

Problem: Can't see deposits
Solution:
  - Make sure filter is set to "PENDING"
  - Check if you're logged in as ADMIN
  - Check internet connection
  - Try hard refresh

Problem: Modal won't open
Solution:
  - Hard refresh the page
  - Clear browser cache
  - Try incognito/private window
  - Check browser console for errors

DEPOSIT STATUS MEANINGS
=======================

🟠 PENDING
  - Awaiting admin review
  - User funds not credited yet
  - Admin can approve or reject

🟢 APPROVED
  - Admin approved the deposit
  - Funds credited to user's wallet
  - Deposit complete

🔴 REJECTED
  - Admin rejected the deposit
  - User can see rejection reason
  - No funds credited
  - User can submit new deposit
